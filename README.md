"And the earth was without form, and void; and darkness was upon the face of the deep."
This is the passage that comes to mind as I think of the new CAD program. The opening screen is the image of darkness and void; there are no coordinate systems when the user logs into the system.
But when the user left-clicks upon the splash screen, then the first coordinate system is created, which is a 2D coordinate system perfectly defined by the corners of the display relative to the observer. There is nothing to indicate the presence of the axes, nor indeed any sign of a drawing program at all.
This is the newest design in CAD, designed to be easy to learn and have no significant conscious memory load. Despite the absence of buttons, there is not a single keyboard shortcut that will work in the current situation. MouseCAD is designed, by default, to be controlled entirely by using the mouse.
The user starts by left-clicking. Immediately, the welding gun appears, and if the user drags, the gun welds a path wherever the gun has touched. On the other hand, if the user lets go of the welding gun and merely moves it around, a welding wire drags out of the tip of the gun. Only when the user clicks is the seam welded. Then a new wire follows around the gun wherever the user takes it. The welding gun is terminated by right-clicking.
In the case where the user drags the welding gun, the resulting shape is calculated once the user "lifts" the torch. This may be a line, circle or arc, open or closed polygon, or a spline.
Any time the user is performing an action with the physical mouse, a status bar is displayed at the top of the screen. This may be a ruler, a timeline, a "highway" (real number line), or a generic progress indicator. At any time, this status bar can be physically manipulated by the user, and may be caused to change its zoom or function by the speed or position of the physical mouse.
When the physical mouse slows significantly, the speed of the indicator dramatically slows, followed by a zoom-in in the status bar to keep the progress moving at the same speed. If the speed of the physical mouse significantly increases, on the other hand, the pointer speed first increases, followed by a zoom-out of the status bar.
At no time is the user required to enter any dimensions. There will be no nasty pop-up text boxes, no complicated lists of parameter settings, only the need to move the mouse in approximately the right direction, at roughly the right relative speed compared to normal preference.
However, there is no need to get the dimensions right the first time; the user merely "selects" an attribute of an entity and right-drags it with the MouseCAD mouse and, using the ruler or highway status bar, defines the dimension.
"Selecting" an entity or an attribute is complicated, and yet so simple. Rectangle selection with "contained" versus "intersected or contained" entities highlighted depending upon which way you drag? Guess again!
Selection is graphical "mouseing," or right-dragging. Where selection is done in an approximately continuous path, the mouse leaves a trail. Whatever the trail intersects is selected once the mouse is released.
If the physical mouse makes a sharp turn after traveling along a short, straight path, however, the result is area selection. The path "sweeps" behind the mouse, normal to its path where its path is continuous and temporarily fixed in orientation when the mouse makes a sharp turn. The result is that everything is selected that falls over halfway within the path.
Everything is an object.
Right-clicking is always a "release" button, or Esc.
All shapes are defined as paths or as shapes. A shape can be directly created by center-clicking or dragging, which is the "metal ladle." The only difference between the metal ladle and the welding gun is that the metal ladle has only the ability to create a closed path, which is defined as being a "shape."
